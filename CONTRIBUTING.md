# Contributing

This repository is maintained by an AI software factory: pull requests here
are opened automatically by that pipeline, not filed directly by humans.
A human reviews and merges each PR before it lands.

If you'd like to see a change — a bug fix, a new feature, anything —
please **open a GitHub issue** describing it. New work is tracked as
issues, and the factory picks those up and turns them into PRs for human
review.
